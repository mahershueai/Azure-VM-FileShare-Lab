# Azure Cloud Lab: VM Deployment & File Share Integration

## 🎯 Objective
Successfully deployed a Windows Server 2019 Virtual Machine on Microsoft Azure and configured an Azure File Share mounted as a network drive (Z:).

## 🛠️ Tasks Completed
- Provisioned an Azure VM (`Standard D2lds_v6`) in the South Central US region.
- Configured RDP access and connected to the VM securely.
- Created an Azure Storage Account and an Azure File Share.
- Mounted the File Share to the VM as a network drive using a PowerShell script (SMB over port 445).
- **Optional Tasks Completed:** 
  - Installed IIS Web Server and published a local HTML page.
  - Installed SQL Server Express.
  - Performed CRUD operations (Create, Read, Update, Delete) on the mounted Azure File Share.
